# Reports

**Paymentology provides end-to-end reporting and reconciliation capabilities to allow you to track all your cards’ financial movements, revenues collected, failed transactions and more**.

You can generate all reports below by sending a HTTP GET Request and downloading the report as a CSV file. These downloadable reports are**only available for 60 days.**

You can generate the following reports:

- [Mark-off file](https://developer.sprint.paymentology.com/card-api/reports/mark-off-file)

- [Summary settlement report](https://developer.sprint.paymentology.com/card-api/reports/summary-settlement-report-2)

- [Detailed settlement report](https://developer.sprint.paymentology.com/card-api/reports/detailed-settlement-report)

- [Forex gains report](https://developer.sprint.paymentology.com/card-api/reports/forex-gains-report-2)

- [Failed transaction report](https://developer.sprint.paymentology.com/card-api/reports/failed-transaction-report-2)

- [Card order report](https://developer.sprint.paymentology.com/card-api/reports/card-order-report-2)

- [eCommerce report](/reports/card-api/ecommerce-report)

- [Inactive cards report](/reports/card-api/inactive-cards-report)

- [Authorisation income report](/reports/card-api/authorisation-income-report)

- [Card balance report](/reports/card-api/card-balance-report)

- [Daily statement report](/reports/card-api/daily-statement-report)

### Card scheme

For clients using Mastercard or Visa, Paymentology can issue the below reports to clients to assist with quarterly card scheme reporting requirements. These reports are sent via email and must first be requested through your Paymentology Client Executive.

- [QVR (Visa) data report](/reports/card-api/qvr-data-report)

- [QMR (Mastercard) data report](/reports/card-api/qmr-data-report)

- [VAU (Visa) transaction report](/reports/card-api/vau-transaction-report)
