# Checksum Generator

​The Checksum Generator​ ​ allows you to calculate the checksum for a transaction based on a terminal password value and the request data.

​

It replicates the same process that happens during authentication. You can use the tool to validate that your own calculated checksum is the same as the one the Paymentology Sprint system generates.

NB. During testing, avoid entering any personally identifiable information (PII), such as, user IDs, card numbers or email addresses.
