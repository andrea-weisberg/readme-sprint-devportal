# SimPOS

SimPOS is a transaction simulator tool that allows you to simulate remote API transactions.

For example: you can use SimPOS to test that the flow of virtual card transactions within the Companion Card API is working properly.

You can find a list of Response codes for the SimPOS testing tool [here](/tools/simpos-result-codes).

NB. During testing, avoid entering any personally identifiable information (PII), such as, user IDs, card numbers or email addresses.
