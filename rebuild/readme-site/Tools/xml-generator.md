# XML Generator

The **XML Generator**​ ​ allows you to generate a valid XML request (including a checksum string) from your request parameters.

​

To ensure compatibility, you can use the tool to confirm if your own generated XML requests, including the checksum, are the same as those generated by Paymentology.

**NB.** **During testing, avoid entering any personally identifiable information (PII), such as - user IDs, card numbers or email addresses.**
