# Devalue

Deducts the requested amount from a card, or pocket if specified, with a redemption type of “Devalue”. The Paymentology issued terminal ID of the terminal requesting the transaction Customer reference linked with this card The tracking number of the card to devalue UUID of the pocket to devalue if applicable. Else, leave empty. The requested amount to be deducted from the card and loaded onto the profile A unique identifier generated by the client, which must not be duplicated over time.
