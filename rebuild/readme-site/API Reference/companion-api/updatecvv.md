# UpdateCVV

Generate a new CVV2 of the specified card. IMPORTANT: This API method contains PCI sensitive information. Session-Id=Encrypted AES Key e-g (AB521456236KHU52) is required if encryption is needed and the campaign is configured for encryption of sensitive data. This is optional if encryption is not needed and the campaign is not configured for encryption of sensitive data. You can read more on how our Secure API's work [here](/guides/secure-apis).
