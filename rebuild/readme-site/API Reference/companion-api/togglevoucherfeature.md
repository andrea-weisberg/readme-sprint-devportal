# ToggleVoucherFeature

Toggles a voucher feature on or off The Paymentology issued terminal ID of the terminal requesting the transaction Customer reference linked with this card The tracking number of the card The name of the feature to disable. Possible values: CREDIT_APPLICATION_ENABLED DAILY_PINLESS_NFC_DISABLED ENABLE_INTERNATIONAL OPT_IN_VAU OPT_OUT_ABU OPT_OUT_VAU PHYSICAL_CARD_DISABLED The status of the feature. Possible values 1 or 0. To enable the feature this should be 1, to disable it this field should be 0. A unique identifier generated by the client, which must not be duplicated over time.
