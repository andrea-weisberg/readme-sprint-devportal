# First Chargeback

After successfully connecting to the API Proxy, you can send the fields/parameters for the API request (as specified below) and receive a response. A successfully submitted First Chargeback will remain in a "pending status" (no more than 72 hours) on issuers' behalf to allow merchants to respond and resolve the inquiry.
