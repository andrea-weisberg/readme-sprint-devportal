Reverse an PocketTransfer transaction that was timed out using the details of the failed transaction.

The Paymentology issued terminal ID of the terminal requesting the transaction

Customer reference linked with card indicated in trackingNumberFrom field

The tracking number of the card that the pockets are linked to

The UUID of the pocket to transfer funds from

The UUID of the pocket to transfer funds to

The requested amount to be loaded on the card and deducted from the profile

A unique identifier generated by the client, which must not be duplicated over time.

Transaction date generated by the calling client

Value of transactionID that was used for original PocketTransfer call

Value of transactionDate that was used for original PocketTransfer call

HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key
