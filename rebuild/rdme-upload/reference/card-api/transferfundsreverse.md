Reverse a TransferFunds transaction that was timed out using the details of the failed transaction.

The Paymentology issued terminal ID of the terminal requesting the transaction

Customer reference linked with this card

The tracking number of the card from which funds were transferred

The tracking number of the card onto which funds were loaded

The UUID of the type of pockets between which the funds were transferred, else empty if not applicable

The amount that was requested in original TransferFunds call

A unique identifier generated by the client, which must not be duplicated over time.

Transaction date generated by the calling client

The value of transactionID that was used with original TransferFunds call

The value of transactionDate that was used with the original TransferFunds call

HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key
