Unstops a token reference or all the ones linked to a card.

The Paymentology issued terminal ID of the terminal requesting the transaction

Profile number linked with this card

The tracking number of the card

The unique reference of the token or an empty string to unstop all the tokens for the card

Usually the same reason used for stopping the token. The reason ID for stopping the token are the same as [DeleteToken](/api-reference/shared/deletetoken).

Description as to why the token was unstopped

Transaction ID number generated by the calling client

Transaction date generated by the calling client
