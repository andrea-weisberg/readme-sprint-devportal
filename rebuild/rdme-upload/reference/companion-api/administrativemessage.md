## Administrative Message - **3DSecureAppAuthentication**

This message is used to trigger the process of cardholder authentication. You only need to respond to this message to indicate you have received the message and will initiate the cardholder authentication. This is then followed by calling Paymentology's [ThreeDSAuthenticationOutcome](/api-reference/companion-api/threedsauthenticationoutcome) API.

The Paymentology issued terminal ID of the terminal requesting the transaction

The reference of the wallet the 3DS authentication is being actioned on

The name of the administrative message being sent - 3DSecureAppAuthentication

The administrative message data sent over in a [KLV format](/guides/klv-lookup). Will contain the following KLV fields:
4 - original transaction amount

43 - merchant description

49 - original currency code

For example: 0040512345examplemerchantabc04903978 would mean 123.45 Euro at examplemerchantabc

Will be the unique transaction ID provided by the ACS.

Transaction date generated by the calling client

HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key

## Administrative Message - **3DSecure.AppFinalisation**

This message is used to inform the client of the final status of the 3DSecure OOB authentication.
Messages include the following:

The Paymentology issued terminal ID of the terminal requesting the transaction

The reference of the wallet the 3DS authentication is being actioned on

The name of the administrative message being sent: 3DSecureAppFinalisation

The adminisrative message data sent over in a [KLV format](/guides/klv-lookup) will contain the following KLV fields: 274 - status.
Values indicating the status:
0 - Successfully received final status
1 - Timer on browser expired before response was received
2 - General error
3 - Transaction cancelled before response was received

Will be the unique transaction ID provided by the ACS.

Transaction date generated by the calling client

HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key
