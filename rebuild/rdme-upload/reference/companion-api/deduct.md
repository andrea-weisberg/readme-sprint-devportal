Deduct the requested amount from a wallet.

The Paymentology issued terminal ID of the terminal requesting the transaction

The reference of the wallet to deduct

The amount to be deducted in cents

A description of the terminal where the card was used

2 character string identifying the type of transaction:

00 = POS

01 = ATM

09 = Cashback at POS

10 = AFT

30 = Balance Inquiry "Used only for Acquirer fees applied on balance inquiry"

Extra information about the transaction in a KLV format

Transaction ID number generated by the calling client. Note that the Transaction ID is not a unique value and may be duplicated over time

Transaction date (in UTC) generated by the calling client

HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key
