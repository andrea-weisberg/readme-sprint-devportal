Notification that a card was stopped.

The Paymentology issued terminal ID of the terminal requesting the transaction

The reference of the wallet

The masked 16 digit PAN that was stopped

The reason id for stopping the card:
1 – Card lost
2 – Card stolen
3 – Pending query
4 – Card consolidation
5 – Card inactive
6 – PIN tries exceeded
7 – Suspected fraud
8 – Card replaced

9 - Stopped to be re-issued

10 - Scheduled stop

11 - Offline PIN attempts exceeded

Extra information about the transaction in a [KLV format](/guides/klv-lookup)

Transaction ID number generated by the calling client. Note that the Transaction ID is not a unique value and may be duplicated over time.

Transaction date generated by the calling client

HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key
