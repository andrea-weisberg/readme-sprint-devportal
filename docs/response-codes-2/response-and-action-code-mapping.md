<p>Each action taken on a transaction is associated with a code; different codes are assigned to the same action by different parties/networks i.e. Mastercard, Visa, Remote API, Transaction Stream.</p>
<p>The table below shows the different codes used by Mastercard, UnionPay and Visa and how they are mapped to <a href="https://developer.sprint.paymentology.com/response-codes-2/">Remote API Response Codes</a> and <a href="https://developer.sprint.paymentology.com/notifications/">Paymentology&#8217;s Transaction Stream (PubNub)</a>.</p>
