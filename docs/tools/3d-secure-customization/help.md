<h2>When to use 3D Secure Screen Customization tool</h2>
<p><span style={{fontWeight: "400"}}>You will use </span><span style={{fontWeight: "400"}}>the</span><span style={{fontWeight: "400"}}> 3D Secure Screen Customization after agreeing to implement the 3D Secure functionality for your chosen API (Card or Companion). </span><span style={{fontWeight: "400"}}>We support different cardholder authentication methods to suit your needs, please choose the tool corresponding to the method you are implementing with Paymentology.</span></p>
<p><b>This tool is for clients who have already signed up with Paymentology and are using the Sprint platform.</b></p>

<h2>How to use the 3D Secure Screen Customization tool</h2>
<p><span style={{fontWeight: "400"}}>First, you must select the type of 3DS Authentication you wish to use. Paymentology currently supports One-time Password (OTP) and Out-of-Band (OOB) authentication methods. </span></p>
<p><span style={{fontSize: "20px"}}><b>One-Time Password Authentication:</b></span></p>
<p><b>Info Screen</b></p>
<ol>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Select the language that will be displayed to your customers. The fixed labels will be translated to the selected language. </span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Upload your logo in either .png or .jpg format.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Select the card scheme – either Mastercard or Visa – in the dropdown box</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the title of your message in the “title” box – default is “Payment confirmation”.</span><span style={{fontWeight: "400"}}> </span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the text for your message in the “Main text” box.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>In the event that the OTP entered is </span><span style={{fontWeight: "400"}}>incorrectly</span><span style={{fontWeight: "400"}}>, enter the text for the error message in the “Wrong OTP Error Message” box.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Select the </span><span style={{fontWeight: "400"}}>number </span><span style={{fontWeight: "400"}}>of minutes the screen should be available before it times out. Maximum time allowed is 15 minutes.</span></li>
</ol>
<p><b>Error Screen</b></p>
<ol>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>This error screen is for any error that is not the incorrect OTP entered. Enter a name for this message in the “title” box.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the text for the message in the “Main text” box.</span></li>
</ol>
<p><span style={{fontSize: "20px"}}><b>Out-of-Band Authentication:</b></span></p>
<p><b>Info Screen</b></p>
<ol>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Select the language that will be displayed to your customers. The fixed labels will be translated to the selected language. </span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Upload your logo in either .png or .jpg format.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Select the card scheme – either Mastercard or Visa – in the dropdown box</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the title of your message in the “title” box – default is “Authentication”. </span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the text for your message in the “Main text” box.</span></li>
</ol>
<p><b>Error Screen</b></p>
<ol>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>The error screen is displayed to the user when a system error occurs during the payment authentication process. Enter a name for this message in the “title” box. </span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the text for the message in the “Main text” box.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Enter the text to direct the cardholder towards your support channels and provide contact details.</span></li>
</ol>

<h2>How to submit your file</h2>
<p><span style={{fontWeight: "400"}}>As you enter all the information, the screen on the right updates so that you have a real-time view of what the screen will look like. Once you are happy with the screens:</span></p>
<ol>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Download the file. It downloads as a zip file with the individual files that are required in the correct formats.</span></li>
<li style={{fontWeight: "400"}} aria-level="1"><span style={{fontWeight: "400"}}>Email this zip file to support@paymentology.com marked for the attention of your Paymentology representative. You will receive a ticket number which you can use to follow up with your Paymentology representative on the progress of your request.</span></li>
</ol>
