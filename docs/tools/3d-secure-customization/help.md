## When to use 3D Secure Screen Customization tool

You will use the 3D Secure Screen Customization after agreeing to implement the 3D Secure functionality for your chosen API (Card or Companion). We support different cardholder authentication methods to suit your needs, please choose the tool corresponding to the method you are implementing with Paymentology.

**This tool is for clients who have already signed up with Paymentology and are using the Sprint platform.**

## How to use the 3D Secure Screen Customization tool

First, you must select the type of 3DS Authentication you wish to use. Paymentology currently supports One-time Password (OTP) and Out-of-Band (OOB) authentication methods.

### One-Time Password Authentication

**Info Screen**

1. Select the language that will be displayed to your customers. The fixed labels will be translated to the selected language.
2. Upload your logo in either .png or .jpg format.
3. Select the card scheme – either Mastercard or Visa – in the dropdown box.
4. Enter the title of your message in the “title” box – default is “Payment confirmation”.
5. Enter the text for your message in the “Main text” box.
6. In the event that the OTP entered is incorrectly, enter the text for the error message in the “Wrong OTP Error Message” box.
7. Select the number of minutes the screen should be available before it times out. Maximum time allowed is 15 minutes.

**Error Screen**

1. This error screen is for any error that is not the incorrect OTP entered. Enter a name for this message in the “title” box.
2. Enter the text for the message in the “Main text” box.

### Out-of-Band Authentication

**Info Screen**

1. Select the language that will be displayed to your customers. The fixed labels will be translated to the selected language.
2. Upload your logo in either .png or .jpg format.
3. Select the card scheme – either Mastercard or Visa – in the dropdown box.
4. Enter the title of your message in the “title” box – default is “Authentication”.
5. Enter the text for your message in the “Main text” box.

**Error Screen**

1. The error screen is displayed to the user when a system error occurs during the payment authentication process. Enter a name for this message in the “title” box.
2. Enter the text for the message in the “Main text” box.
3. Enter the text to direct the cardholder towards your support channels and provide contact details.

## How to submit your file

As you enter all the information, the screen on the right updates so that you have a real-time view of what the screen will look like. Once you are happy with the screens:

1. Download the file. It downloads as a zip file with the individual files that are required in the correct formats.
2. Email this zip file to [support@paymentology.com](mailto:support@paymentology.com) marked for the attention of your Paymentology representative. You will receive a ticket number which you can use to follow up with your Paymentology representative on the progress of your request.
