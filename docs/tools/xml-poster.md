[The **XML Poster**](https://developer.sprint.paymentology.com/tools/runxmlrpcrequest/runxmlrpcrequesthelp) allows you to post XML requests directly to the Paymentology Sprint system.

In the event that there is no alternative route, you can use the XML Poster to post requests created with the XML Generator to Paymentology.

For example:  
When you begin testing, you’ll not yet have a system in place for calling the Companion Card Local API. You can, therefore, use this tool to post requests to the API directly — like when creating your first test card.

**NB.** **During testing, avoid entering any personally identifiable information (PII), such as, user IDs, card numbers or email addresses.**
