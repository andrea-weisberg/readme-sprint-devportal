<p>SimPOS is a transaction simulator tool that allows you to simulate remote API transactions.</p>
<p>For example: you can use SimPOS to test that the flow of virtual card transactions within the Companion Card API is working properly.</p>
<p>You can find a list of Response codes for the SimPOS testing tool <a href="https:developer.sprint.paymentology.com/tools/simpos/simpos-result-codes/">here</a>.</p>
<p><strong>NB.</strong> <strong>During testing, avoid entering any personally identifiable information (PII), such as, user IDs, card numbers or email addresses.</strong></p>
