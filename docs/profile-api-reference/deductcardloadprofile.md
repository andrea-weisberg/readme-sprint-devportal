<p class="method">Deduct requested amount from card and load the amount back to the profile.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile to which the card belongs, funds will be loaded to this profile</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, tracking number or sequence number of the card to deduct</p> |
| requestAmount | Integer |  | ✓ | <p>The requested amount to be deducted from the card and loaded onto the profile, in cents</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

#### Response schema

| Field | Type | Description |
|---|---|---|
| terminalID | String | <p>Echo of incoming value</p> |
| profileNumber | String | <p>Echo of incoming value</p> |
| cardNumber | String | <p>Number of the card found using the cardIdentifier</p> |
| requestAmount | Integer | <p>Echo of incoming value</p> |
| clientTransactionID | String | <p>Echo of incoming value</p> |
| serverTransactionID | Date | <p>Transaction ID generated by Paymentology</p> |
| balanceAmount | Integer | <p>Balance amount in cents</p> |
| authNumber | String | <p>Authorisation number for transaction</p> |
| expiryDate | Date | <p>The expiry date of the card</p> |
| TransactionFee | Integer | <p>Transaction fee amount in cents</p> |
| resultCode | Integer | <p>Status code indicating transaction result</p> |
| resultText | String | <p>Text indicating transaction result</p> |
