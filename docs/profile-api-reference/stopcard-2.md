<p>Stop a card with one of the following allowed (integer) values for <span class="xml-highlight">stopReasonID</span>:</p>
<ol>
<li>Card stopped as it has been lost</li>
<li>Card stopped as it has been stolen</li>
<li>Card stopped pending outcome of query</li>
<li>Card stopped to consolidate onto single card</li>
<li>Card stopped as it is no longer active</li>
<li>Card stopped as allowable PIN tries have been exceeded</li>
<li>Suspected fraud</li>
<li>Emergency card replacement</li>
</ol>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>Profile number linked with this card</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>Card number or Tracking number or Sequence number of the card</p> |
| stopReasonID | Integer |  | ✓ | <p>Stop Reason ID associated with the reason for stopping a card:</p> <ol> <li>Card stopped as it has been lost</li> <li>Card stopped as it has been stolen</li> <li>Card stopped pending outcome of query</li> <li>Card stopped to consolidate onto single card</li> <li>Card stopped as it is no longer active</li> <li>Card stopped as allowable PIN tries have been exceeded</li> <li>Suspected fraud</li> <li>Emergency card replacement</li> </ol> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
