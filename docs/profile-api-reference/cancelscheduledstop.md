<p class="method">Cancels an existing scheduled stop. Will return an error if there is no scheduled stop for this card.</p>



<!-- spacing: desktop=20, mobile=10 -->

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Profile number linked with this card.</p> </div> </div> |
| cardIdentifier | String | 1-20 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>The card number, sequence number or tracking number of the specified card.</p> </div> </div> |
| transactionID | String | 1-255 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Transaction ID number generated by the calling client.</p> </div> </div> |
| transactionDate | Date |  | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Transaction date generated by the calling client.</p> </div> </div> |
| checksum | String |  | ✓ | <section class="tutuka-block tutuka-block--api-request"> <div class="api-reference"> <div class="api-reference__single"> <div class="params-wrapper"> <div class="param-single d-flex"> <div class="info"> <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> </div> </div> </div> </div> </div> </section> |
