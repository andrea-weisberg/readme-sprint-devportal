Updates the firstName, lastName, cellphone and ID number linked to an allocated card.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction. |
| profileNumber | String | 1-20 characters | ✓ | The profile to which the card belongs. |
| cardIdentifier | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card to update. |
| firstName | String | 1-100 characters | ✓ | The first name of the card bearer. |
| lastName | String | 1-100 characters | ✓ | The last name of the card bearer. |
| idOrPassportNumber | String | 1-50 characters | ✓ | The ID or passport number of the card bearer. |
| cellphoneNumber | String | 1-20 characters | ✓ | The cellphone number of the card bearer. |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client. |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |
