- SMS Balance Enquiry

- ATM Balance Enquiry

- ATM Balance Enquiry – Agent Bank

- ATM Cash Withdrawal

- ATM Cash Withdrawal – Agent Bank

- POS Purchase

- POS Purchase with Cashback

- Cashout

#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| profileNumber | String | 1-20 characters | ✓ | The profile to which the card belongs |
| cardIdentifier | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card to charge the fee |
| feeTypeID | Integer |  | ✓ | The identifier depicting the type of fee to be deducted. (List in method description above) |
| requestAmount | Integer |  | ✓ | The requested amount to be deducted from the card as a fee, in cents |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String | 1-255 characters | ✓ | HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
