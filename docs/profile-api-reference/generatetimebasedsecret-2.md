<section id="tutuka-block-1" class="tutuka-block tutuka-block--text-full-width">
<div class="tutuka-block--text-full-width__content">
<p>Generates a “secret token” to enable communication with our tokenisation APIs.</p>
<p><strong>IMPORTANT:</strong> As push provisioning needs to be completed in one minute or less, the recommended setting for the Request Parameter: <span style="text-decoration: underline;">timeStep</span> is 60.</p>
</div>
</section>



\{/* spacing: desktop=20, mobile=10 */\}


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>The Paymentology issued terminal ID of the terminal requesting the transaction.</p> </div> </div> |
| customerReference | String |  1-255 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Customer reference linked with this card.</p> </div> </div> |
| trackingNumber | String |   1-20 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Tracking number that identifies the card to be returned.</p> </div> </div> |
| timeStep | Integer |  | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Default: <strong>60</strong> – Window during which TOTP is valid in seconds.</p> <p><strong>IMPORTANT:</strong> This is the default and recommended setting as push provisioning needs to be completed in one minute or less.</p> </div> </div> |
| cardSecretLength | Integer |  | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Default: <strong>8</strong> – Length of card secret 1-8.</p> </div> </div> |
| algorithm | String |  | ✓ | <p>Default: <strong>HmacSHA512</strong> – Hashing algorithm used for TOTP generation</p> <p>Possible Values:</p> <p>HmacSHA1, HmacSHA256, HmacSHA512</p> |
| transactionID | String | 1-255 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Transaction ID number generated by the calling client.</p> </div> </div> |
| transactionDate | String |  | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Transaction date generated by the calling client.</p> </div> </div> <div class="param-single d-flex"></div> |
| checksum | String | 1-255 characters | ✓ | <section class="tutuka-block tutuka-block--api-request"> <div class="api-reference"> <div class="api-reference__single"> <div class="params-wrapper"> <div class="param-single d-flex"> <div class="info"> <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> </div> </div> </div> </div> </div> </section> |
