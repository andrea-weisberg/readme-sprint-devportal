<p>Reverse a previous DevalueProfile request.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile which was devalued, funds will be returned to this profile.</p> |
| requestAmount | Integer |  | ✓ | <p>The requested amount which was deducted from the profile, in cents.</p> |
| referenceID | String | 1-255 characters | ✓ | <p>The Transaction ID of the original transaction to be reversed.</p> |
| referenceDate | Date |  | ✓ | <p>The Transaction date of the original transaction to be reversed.</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |
