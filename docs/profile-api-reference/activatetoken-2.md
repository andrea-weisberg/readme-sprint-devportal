<p>Used to activate a token for a digitization that has been approved and provisioned, but requires additional cardholder authentication prior to activation.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>Profile number linked with this card</p> |
| trackingNumber | String | 1-10 characters | ✓ | <p>The tracking number of the card</p> |
| tokenUniqueReference | String | 48 characters | ✓ | <p>The unique reference of the token</p> |
| activationCode | String |  | ✓ | <p>Required when card scheme is VISA (empty string otherwise)</p> |
| reasonCode | String |  | ✓ | <p>Reason for the activation. Valid values:<br /> ‘A’ – Cardholder successfully authenticated prior to activation<br /> ‘C’ – Cardholder successfully authenticated with a customer service agent prior to activation</p> |
| comment | String | 1-500 characters | ✓ | <p>Description of the activation or empty string</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
