Toggles a voucher feature on or off


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| profileNumber | String | 1-20 characters | ✓ | Profile number linked with this card |
| cardIdentifier | String | 1-20 characters | ✓ | The card number, sequence number or tracking number of the specified card. |
| featureName | String | 1-255 characters | ✓ | Name of the feature to be enabled/disabled.<br><br>Possible values:<br><br>ENABLE_INTERNATIONAL<br><br>OPT_IN_VAU<br><br>OPT_OUT_ABU<br><br>OPT_OUT_VAU<br><br>ATM_ENABLED<br><br>NFC_ENABLED<br><br>POS_ENABLED<br><br>ECOM_ENABLED |
| featureStatus | Boolean |  | ✓ | Status to be applied.(True/False) |
| transactionID | String | 1-255 characters | ✓ | A unique identifier generated by the client, which must not be duplicated over time. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String | 1-255 characters | ✓ | HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |
