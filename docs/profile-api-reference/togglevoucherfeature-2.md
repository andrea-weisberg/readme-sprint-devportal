<p>Toggles a voucher feature on or off</p>



\{/* spacing: desktop=20, mobile=10 */\}


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p><span data-teams="true">The Paymentology issued terminal ID of the terminal requesting the transaction</span></p> |
| profileNumber | String | 1-20 characters | ✓ | <p>Profile number linked with this card</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p><span data-teams="true">The card number, sequence number or tracking number of the specified card.</span></p> |
| featureName | String | 1-255 characters | ✓ | <p>Name of the feature to be enabled/disabled.</p> <p>Possible values:</p> <p>ENABLE_INTERNATIONAL</p> <p>OPT_IN_VAU</p> <p>OPT_OUT_ABU</p> <p>OPT_OUT_VAU</p> <p>ATM_ENABLED</p> <p>NFC_ENABLED</p> <p>POS_ENABLED</p> <p>ECOM_ENABLED</p> |
| featureStatus | Boolean |  | ✓ | <p>Status to be applied.(True/False)</p> |
| transactionID | String | 1-255 characters | ✓ | <p><span data-teams="true">A unique identifier generated by the client, which must not be duplicated over time.</span></p> |
| transactionDate | Date |  | ✓ | <p><span data-teams="true">Transaction date generated by the calling client</span></p> |
| checksum | String | 1-255 characters | ✓ | <p><span data-teams="true">HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</span></p> |
