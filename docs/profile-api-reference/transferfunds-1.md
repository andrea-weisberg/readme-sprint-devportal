Transfer funds from one card to another.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| profileNumber | String | 1-20 characters | ✓ | The profile to which the card belongs, funds will be loaded to this profile |
| cardIdentifierFrom | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card to deduct |
| cardIdentifierTo | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card to load |
| requestAmount | Integer |  | ✓ | The requested amount to be loaded on the card and deducted from the profile, in cents |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
