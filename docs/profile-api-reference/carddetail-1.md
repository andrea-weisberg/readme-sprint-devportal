<p>Returns details regarding the created virtual card.</p>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| voucherNumber | String | 16 characters | ✓ | <p>The Paymentology issued virtual card we want to get additional details for</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

#### Response schema

| Field | Type | Description |
|---|---|---|
| CVV2 | String | <p>The CVV2 code created for this virtual card</p> |
| ExpiryDate | String | <p>The expiration date for this virtual card, ie ‘2013-11-30 00:00:00’</p> |
| IsActivated | Boolean | <p>Indicates if the card is activated or not</p> |
| IsRetired | Boolean | <p>Indicates if the card if retired or not</p> |
| IsStopped | Boolean | <p>Indicates if the card is stopped or not</p> |
| BalanceAmount | Integer | <p>The balance the card has left in cents</p> |
| clientTransactionID | String | <p>Echo</p> |
| serverTransactionID | String | <p>Transaction ID generated by Paymentology</p> |
| resultCode | Integer | <p>Status code indicating the method call result</p> |
| resultText | String | <p>Status text indicating the method call result</p> |
