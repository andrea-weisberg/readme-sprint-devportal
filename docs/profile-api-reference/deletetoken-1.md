<p>Remove a payment token linked to a card</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>Profile number linked with this card</p> |
| trackingNumber | String | 1-10 characters | ✓ | <p>The tracking number of the card of which to remove the payment token from</p> |
| tokenUniqueReference | String | 48 characters | ✓ | <p>The unique reference of the token</p> |
| stopReasonID | Integer |  | ✓ | <p data-renderer-start-pos="6523">Stop reason associated with the reason for stopping the token or tokens.</p> <p data-renderer-start-pos="6597">The reason ID for stopping the token:</p> <p data-renderer-start-pos="6636">1 – Card lost</p> <p data-renderer-start-pos="6651">2 – Card stolen</p> <p data-renderer-start-pos="6668">3 – Pending query</p> <p data-renderer-start-pos="6687">4 – Card consolidation</p> <p data-renderer-start-pos="6711">5 – Card inactive</p> <p data-renderer-start-pos="6730">6 – PIN tries exceeded</p> <p data-renderer-start-pos="6754">7 – Suspected fraud</p> <p data-renderer-start-pos="6775">8 – Card replaced</p> |
| comment | String | 1-500 characters | ✓ | <p>Description as to why the token was deleted</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
