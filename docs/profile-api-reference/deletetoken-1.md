Remove a payment token linked to a card


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| profileNumber | String | 1-20 characters | ✓ | Profile number linked with this card |
| trackingNumber | String | 1-10 characters | ✓ | The tracking number of the card of which to remove the payment token from |
| tokenUniqueReference | String | 48 characters | ✓ | The unique reference of the token |
| stopReasonID | Integer |  | ✓ | Stop reason associated with the reason for stopping the token or tokens.<br><br>The reason ID for stopping the token:<br><br>1 – Card lost<br><br>2 – Card stolen<br><br>3 – Pending query<br><br>4 – Card consolidation<br><br>5 – Card inactive<br><br>6 – PIN tries exceeded<br><br>7 – Suspected fraud<br><br>8 – Card replaced |
| comment | String | 1-500 characters | ✓ | Description as to why the token was deleted |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String |  | ✓ | HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
