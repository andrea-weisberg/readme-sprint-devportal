Updates a profile owner’s details.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Tutuka issued terminal ID of the terminal requesting the transaction. |
| profileNumber | String | 1-20 characters | ✓ | The Profile number for which the owner details will be updated. |
| emailAddress | String |  | ✓ | Unique email address for this profile (only 1 profile allowed per email address). |
| password | String |  | ✓ | A user defined password for this profile (only important when authenticating using the Tutuka authentication). |
| firstName | String | 1-100 characters | ✓ | Profile owner first name. |
| lastName | String | 1-100 characters | ✓ | Profile owner last name. |
| idOrPassportNumber | String | 1-50 characters | ✓ | Profile owner official ID document number (requires FICA in some cases). |
| contactNumber | String |  | ✓ | Profile owner contact number. |
| cellphoneNumber | String | 1-20 characters | ✓ | Profile owner cellphone number. |
| isCompany | Boolean |  | ✓ | Profile owner is a registered company: true or false. |
| vatNumber | String | 1-20 characters | ✓ | Profile company VAT number. |
| companyName | String | 1-100 characters | ✓ | Profile company name. |
| companyCCNumber | String |  | ✓ | Profile company CC number. |
| addressLine1 | String | 1-100 characters | ✓ | Profile owner first address line. |
| addressLine2 | String | 1-100 characters | ✓ | Profile owner second address line. |
| city | String | 1-100 characters | ✓ | Profile owner address city (or state). |
| postalCode | String |  | ✓ | Profile owner address postal code. |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client. |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |
