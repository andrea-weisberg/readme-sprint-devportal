<p>Updates a profile owner’s details.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Tutuka issued terminal id of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The Profile number for which the owner details will be updated.</p> |
| emailAddress | String |  | ✓ | <p>Unique email address for this profile (only 1 profile allowed per email address).</p> |
| password | String |  | ✓ | <p>A user defined password for this profile (only important when authenticating using the Tutuka authentication).</p> |
| firstName | String | 1-100 characters | ✓ | <p>Profile owner first name.</p> |
| lastName | String | 1-100 characters | ✓ | <p>Profile owner last name.</p> |
| idOrPassportNumber | String | 1-50 characters | ✓ | <p>Profile owner official id document number (requires FICA in some cases).</p> |
| contactNumber | String |  | ✓ | <p>Profile owner contact number.</p> |
| cellphoneNumber | String | 1-20 characters | ✓ | <p>Profile owner cellphone number.</p> |
| isCompany | Boolean |  | ✓ | <p>Profile owner is a registered company: true or false.</p> |
| vatNumber | String | 1-20 characters | ✓ | <p>Profile company VAT number.</p> |
| companyName | String | 1-100 characters | ✓ | <p>Profile company name.</p> |
| companyCCNumber | String |  | ✓ | <p>Profile company CC number.</p> |
| addressLine1 | String | 1-100 characters | ✓ | <p>Profile owner first address line.</p> |
| addressLine2 | String | 1-100 characters | ✓ | <p>Profile owner second address line.</p> |
| city | String | 1-100 characters | ✓ | <p>Profile owner address city (or state).</p> |
| postalCode | String |  | ✓ | <p>Profile owner address postal code.</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction id number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |
