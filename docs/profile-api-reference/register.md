Creates and registers a new profile.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| emailAddress | String |  | ✓ | Unique email address for this profile (only 1 profile allowed per email address) |
| password | String |  | ✓ | A user defined password for this profile (only important when authenticating using the Paymentology authentication) |
| firstName | String | 1-50 characters | ✓ | Profile owner first name |
| lastName | String | 1-50 characters | ✓ | Profile owner last name |
| idOrPassportNumber | String |  | ✓ | Profile owner official ID document number (requires FICA in some cases) |
| contactNumber | String | 1-10 characters | ✓ | Profile owner contact number |
| cellphoneNumber | String | 1-10 characters | ✓ | Profile owner cellphone number |
| isCompany | Boolean |  | ✓ | Profile owner is a registered company.<br><br>Possible values:<br><br>**0** (false)<br><br>**1** (true) |
| vatNumber | String | 1-20 characters | ✓ | Profile company VAT number |
| companyName | String | 1-50 characters | ✓ | Profile company name |
| companyCCNumber | String | 1-20 characters | ✓ | Profile company CC number |
| addressLine1 | String | special - see description | ✓ | This is the first line of the address field which will be printed on a card mailer when required by the client – maximum length is 27 to 60 characters (Manufacturer dependent).<br><br>The field may not start (first character) with a comma, linefeed character, carriage return character, quotation marks or question mark. |
| addressLine2 | String | special - see description | ✓ | This is the second line of the address field which will be printed on a card mailer when required by the client – maximum length is 27 to 60 characters (Manufacturer dependent).<br><br>The field may not start (first character) with a comma, linefeed character, carriage return character, quotation marks or question mark. |
| city | String |  | ✓ | Profile owner address city (or state) |
| postalCode | String |  | ✓ | Profile owner address postal code |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
