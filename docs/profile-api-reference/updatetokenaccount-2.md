<p>Updates the card PAN information associated with a token</p>



\{/* spacing: desktop=20, mobile=10 */\}


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>Profile number linked with this card</p> |
| oldCardIdentifier | String | 1-10 characters | ✓ | <p>Card number or tracking number of the card to transfer the token from</p> |
| newCardIdentifier | String | 1-10 characters | ✓ | <p>Card number or tracking number of the card to transfer the token to</p> |
| expiryDate | Date |  | ✓ | <p>Date which specifies when the card expires</p> |
| reasonCode | String |  | ✓ | <p data-renderer-start-pos="53662">Reason for the update. Valid values:</p> <p data-renderer-start-pos="53700">‘ACCOUNT_UPDATE’ – VoucherID Update</p> <p data-renderer-start-pos="53737">‘EXP_DATE_UPDATE’ – Expiry Update</p> <p data-renderer-start-pos="53772">‘ACCOUNT_CLOSED’ – Account Deletion</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
