<p>Reverse a VAS transfer on the card.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile to which the card belongs.</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, tracking number or sequence number of the card to load.</p> |
| OriginalRequestAmount | Integer |  | ✓ | <p>The requested amount to be deducted from the card, in cents.</p> |
| OriginalTransactionID | String | 1-255 characters | ✓ | <p>TransactionID of the transaction to be reversed.</p> |
| OriginalTransactionReference | String | 1-255 characters | ✓ | <p>Original transaction reference to be reversed.</p> |
| OriginalTransactionDate | Date |  | ✓ | <p>Date of the original transaction to be reversed.</p> |
| transactionID | String |  | ✓ | <p>Transaction id number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |
