Reverse a VAS transfer on the card.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction. |
| profileNumber | String | 1-20 characters | ✓ | The profile to which the card belongs. |
| cardIdentifier | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card to load. |
| OriginalRequestAmount | Integer |  | ✓ | The requested amount to be deducted from the card, in cents. |
| OriginalTransactionID | String | 1-255 characters | ✓ | TransactionID of the transaction to be reversed. |
| OriginalTransactionReference | String | 1-255 characters | ✓ | Original transaction reference to be reversed. |
| OriginalTransactionDate | Date |  | ✓ | Date of the original transaction to be reversed. |
| transactionID | String |  | ✓ | Transaction ID number generated by the calling client. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client. |
| checksum | String |  | ✓ | HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |
