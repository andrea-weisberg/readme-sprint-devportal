<p>Updates the cellphone or id number linked to an allocated card.</p>
<p><strong>IMPORTANT:</strong> Validation is performed on the cellPhone parameter value of the request message.</p>
<p>cellPhone input format allows:</p>
<ul>
<li>10 digits and starts with 0 (example: 0123456789) <strong>or</strong></li>
<li>11 digits and starts with 27 (example: 27123456789)</li>
</ul>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile to which the card belongs.</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, tracking number or sequence number of the card to update.</p> |
| idOrPassport | String | 1-50 characters | ✓ | <p>The id or passport number of the card bearer.</p> |
| cellphoneNumber | String | 10-11 digits | ✓ | <p>The cellphone number of the card bearer.</p> <p>Valid formats:</p> <p>10 digits and starts with 0 (example: 0123456789) <strong>or<br  /> </strong>11 digits and starts with 27 (example: 27123456789)</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction id number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |
