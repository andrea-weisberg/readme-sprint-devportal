<p>Allocate an IBAN [Account Number] for a card linked to the specified profile.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 charcaters | ✓ | <p>Profile number linked with this card.</p> |
| cardidentifier | String | 1-20 charcaters | ✓ | <p>The card number, sequence number or tracking number of the specified card.</p> |
| transactionID | String | 1-255 charcaters | ✓ | <p>Transaction id number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| Checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |
