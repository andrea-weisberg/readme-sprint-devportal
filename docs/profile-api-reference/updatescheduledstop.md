Updates an existing scheduled stop.

Will return an error if there is no scheduled stop for this card.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction. |
| profileNumber | String | 1-20 characters | ✓ | The profile to devalue, funds will be deducted from this profile. |
| cardIdentifier | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card which the SMS notification number is to be changed. |
| stopDate | Date |  | ✓ | The day when the card will be stopped. |
| stopReasonID | Integer |  | ✓ | Stop Reason ID associated with the reason for stopping a card. |
| stopComment | String | 1-255 characterss | ✓ | Any additional remarks describing the stop. |
| transactionID | String | 1-255 characterss | ✓ | Transaction ID number generated by the calling client. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client. |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |
