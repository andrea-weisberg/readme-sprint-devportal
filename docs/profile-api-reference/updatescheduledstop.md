<p>Updates an existing scheduled stop.</p>
<p>Will return an error if there is no scheduled stop for this card.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile to devalue, funds will be deducted from this profile.</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, tracking number or sequence number of the card which the SMS notification number is to be changed.</p> |
| stopDate | Date |  | ✓ | <p>The day when the card will be stopped.</p> |
| stopReasonID | Integer |  | ✓ | <p>Stop Reason ID associated with the reason for stopping a card.</p> |
| stopComment | String | 1-255 characterss | ✓ | <p>Any additional remarks describing the stop.</p> |
| transactionID | String | 1-255 characterss | ✓ | <p>Transaction ID number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |
