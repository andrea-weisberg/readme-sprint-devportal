Unstops a token reference or all the ones linked to a card.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| profileNumber | String | 1-20 characters | ✓ | Profile number linked with this card |
| trackingNumber | String | 1-10 characters | ✓ | The tracking number of the card |
| tokenUniqueReference | String | 48 characters, | ✓ | The unique reference of the token or an empty string to unstop all the tokens for the card |
| unStopReasonID | Integer |  | ✓ | Usually the same reason used for stopping the token. The reason ID for stopping the token are the same as [DeleteToken](deletetoken-1). |
| comment | String | 1-500 characters | ✓ | Description as to why the token was unstopped |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String |  | ✓ | HMAC-SHA1 or HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
