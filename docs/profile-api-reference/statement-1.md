<p>Retrieve the statement of a card.</p>
<p><strong>NOTE:</strong> Do not use the Statement method when the Balance method will be sufficient, as the Statement method may take considerably longer to return a response.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile to which the card belongs.</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, tracking number or sequence number of the card to retrieve the statement for.</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction id number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |

#### Response schema

| Field | type | Description |
|---|---|---|
| terminalID | String | <p>Echo of incoming value.</p> |
| profileNumber | String | <p>Echo of incoming value.</p> |
| cardNumber | String | <p>Number of the card found using the cardIdenitifier.</p> |
| balanceAmount | Integer | <p>Balance amount in cents.</p> |
| expiryDate | Date | <p>The expiry date of the card.</p> |
| statement | Array | <p>The transaction history of the card.</p> <p>The array includes:<br  /> <strong>transactionDate</strong> – Date of the transaction (date)<br  /> <strong>transactionAmount</strong> – Amount of the transactionin cents (integer)<br  /> <strong>transactionDescription</strong> – name of the merchant where the transaction originated (string)<br  /> <strong>transactionType</strong> – type of the transaction:<br  /> 1. load<br  /> 2. deduction<br  /> 3. authorisation<br  /> (integer)</p> |
| clientTransactionID | String | <p>Echo of incoming value.</p> |
| serverTransactionID | Date | <p>Transaction id generated by Paymentology.</p> |
| resultCode | Integer | <p>Status code indicating the transaction result.</p> |
| resultText | String | <p>Text indicating the transaction result.</p> |
