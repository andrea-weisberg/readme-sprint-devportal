Schedules the stop of the card on the date of the parameter. There can only be one active scheduled stop for a card.

Will return an error if the schedule already exists.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction. |
| profileNumber | String | 1-20 characters | ✓ | Profile number linked with this card. |
| cardIdenitifier | String | 1-20 characters | ✓ | The card number, sequence number or tracking number of the specified card. |
| stopDate | Date |  | ✓ | The day when the card will be stopped. |
| stopReasonID | Integer |  | ✓ | Stop Reason ID associated with the reason for stopping a card. |
| stopComment | String |  | ✓ | Any additional remarks describing the stop. |
| transactionID | String | 1-255 charcters | ✓ | Transaction ID number generated by the calling client. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client. |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |
