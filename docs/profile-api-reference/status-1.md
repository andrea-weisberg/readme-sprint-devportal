Retrieve the current status of a card.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction. |
| profileNumber | String | 1-20 characters | ✓ | The profile to which the card belongs. |
| cardIdentifier | String | 1-20 characters | ✓ | The card number, tracking number or sequence number of the card to retrieve the status of. |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client. |
| checksum | String |  | ✓ | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key. |

#### Response schema

| Parameter | type | Description |
| --- | --- | --- |
| expired | Boolean | Is the card expired. |
| retired | Boolean | Is the card retired. |
| stopped | Boolean | Is the card stopped. |
| stolen | Boolean | Is the card stolen. |
| valid | Boolean | Is the card valid. |
| cancelled | Boolean | Is the card cancelled. |
| loaded | Boolean | Has the card been loaded. |
| lost | Boolean | Is the card marked as lost. |
| activated | Boolean | Is the card activated. |
| redeemed | Boolean | Has the card been redeemed. |
| empty | Boolean | Is the card empty. |
| pinBlocked | Boolean | Has the PIN code been blocked. |
| clientTransactionID | String | Echo of the incoming value. |
| serverTransactionID | Date | Transaction ID generated by Paymentology. |
| resultCode | Integer | Status code indicating the transaction result. |
| resultText | String | Text indicating the transaction result. |
