<p>Retrieve the current status of a card.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction.</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>The profile to which the card belongs.</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, tracking number or sequence number of the card to retrieve the status of.</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client.</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key.</p> |

#### Response schema

| Field | Type | Description |
|---|---|---|
| expired | Boolean | <p>Is the card expired.</p> |
| retired | Boolean | <p>Is the card retired.</p> |
| stopped | Boolean | <p>Is the card stopped.</p> |
| stolen | Boolean | <p>Is the card stolen.</p> |
| valid | Boolean | <p>Is the card valid.</p> |
| cancelled | Boolean | <p>Is the card cancelled.</p> |
| loaded | Boolean | <p>Has the card been loaded.</p> |
| lost | Boolean | <p>Is the card marked as lost.</p> |
| activated | Boolean | <p>Is the card activated.</p> |
| redeemed | Boolean | <p>Has the card been redeemed.</p> |
| empty | Boolean | <p>Is the card empty.</p> |
| pinBlocked | Boolean | <p>Has the PIN code been blocked.</p> |
| clientTransactionID | String | <p>Echo of the incoming value.</p> |
| serverTransactionID | Date | <p>Transaction ID generated by Paymentology.</p> |
| resultCode | Integer | <p>Status code indicating the transaction result.</p> |
| resultText | String | <p>Text indicating the transaction result.</p> |
