<p>Create a virtual card with specified amount loaded, linked to the specified profile and allocated to a cardholder with specified details.</p>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| profileNumber | String | 1-20 characters | ✓ | <p>Profile number linked with this card</p> |
| loadAmount | Integer |  | ✓ | <p>Amount loaded on card</p> <p>NB. A Virtual Card can be created without having any amount loaded on it</p> |
| firstName | String | 1-50 characters | ✓ | <p>The first name of the bearer</p> |
| lastName | String | 1-50 characters | ✓ | <p>The last name of the bearer</p> |
| idOrPassportNumber | String | 1-50 characters | ✓ | <p>The identification number or passport number for the bearer</p> |
| cellPhoneNumber | String | 1-10 characters | ✓ | <p>The Mobile Phone Number of the bearer</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
