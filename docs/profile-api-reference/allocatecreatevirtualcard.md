Create a virtual card with specified amount loaded, linked to the specified profile and allocated to a cardholder with specified details.


#### Path parameters

| Parameter | type | Limits | required | Description |
| --- | --- | --- | --- | --- |
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal ID of the terminal requesting the transaction |
| profileNumber | String | 1-20 characters | ✓ | Profile number linked with this card |
| loadAmount | Integer |  | ✓ | Amount loaded on card<br><br>NB. A Virtual Card can be created without having any amount loaded on it |
| firstName | String | 1-50 characters | ✓ | The first name of the bearer |
| lastName | String | 1-50 characters | ✓ | The last name of the bearer |
| idOrPassportNumber | String | 1-50 characters | ✓ | The identification number or passport number for the bearer |
| cellPhoneNumber | String | 1-10 characters | ✓ | The Mobile Phone Number of the bearer |
| transactionID | String | 1-255 characters | ✓ | Transaction ID number generated by the calling client |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String |  | ✓ | HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
