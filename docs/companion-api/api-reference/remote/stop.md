<p>Notification that a card was stopped.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| reference | String | 1-255 characters | ✓ | <p>The reference of the wallet</p> |
| voucherNumber | String |  | ✓ | <p>The masked 16 digit PAN that was stopped</p> |
| stopReason | Integer |  | ✓ | <p>The reason id for stopping the card:<br  /> 1 – Card lost<br  /> 2 – Card stolen<br  /> 3 – Pending query<br  /> 4 – Card consolidation<br  /> 5 – Card inactive<br  /> 6 – PIN tries exceeded<br  /> 7 – Suspected fraud<br  /> 8 – Card replaced</p> <p>9 – Stopped to be re-issued</p> <p>10 – Scheduled stop</p> <p>11 – Offline PIN attempts exceeded</p> |
| transactionData | String | 0-2048 characters | ✓ | <p>Extra information about the transaction in a <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">KLV format</a></p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction id number generated by the calling client. Note that the Transaction id is not a unique value and may be duplicated over time.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
