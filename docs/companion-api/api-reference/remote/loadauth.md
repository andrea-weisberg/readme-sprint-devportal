<p>Sends the request to preload in case of a refund request or a request to load a card.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| reference | String | 1-255 characters | ✓ | <p>The reference of the wallet to load</p> |
| requestAmount | Integer |  | ✓ | <p>The amount to be loaded in cents</p> |
| narrative | String | 1-255 characters | ✓ | <p>A description of the terminal where the card was used</p> |
| transactionType | String | 2 characters | ✓ | <p>2 character string identifying the type of transaction:</p> <p>20 = Refund<br /> 26 = OCT (Visa)<br /> 28 = MoneySend/Payment</p> |
| transactionData | String | 0-2048 characters | ✓ | <p>Extra information about the transaction in a <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">KLV format</a></p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client.</p> <p><em>Note. The transactionID is not a unique value and may be duplicated over time. The value of the transactionID is not expected or guaranteed to tie up to an original deduct message.</em></p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
