<h1><a id="Tokenization"></a>Administrative Message &#8211; Tokenization Related Messages</h1>
<p>Sends tokenization related messages to the client.</p>
<p>Please click <a href="https://developer.sprint.paymentology.com/administrative-message-values/">here</a> for more information on <span class="xml-highlight">messageName </span>data field and the related data which is sent with these messages.</p>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| reference | String | 1-255 characters | ✓ | <p>The reference of the wallet to retrieve the balance for</p> |
| messageName | String | 0-2048 characters | ✓ | <p>The name of the administrative message being sent. Please see method description for more information in this field. Click <a href="https://developer.sprint.paymentology.com/administrative-message-values/">here</a> for more info on the types of messages for this field.</p> |
| messageData | String | 0-2048 characters | ✓ | <p>The administrative message data sent over in a <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">KLV format</a></p> |
| transactionID | String | 1-255 characters | ✓ | <p>Transaction ID number generated by the calling client. Note that the Transaction ID is not a unique value and may be duplicated over time.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

<h1><a id="3DSecure"></a>Administrative Message &#8211; 3D Secure OTP</h1>
<p>Sends message with 3D Secure OTP</p>
<p>&nbsp;</p>
<p>KLV data – ‘3D Secure OTP’ = 900.</p>
<p><em data-renderer-mark="true">Only if the 3DS validation option is &#8216;SMS OTP&#8217;:</em></p>
<p>‘Original transaction amount ’ = 004, ‘merchant description’ = 043, original currency code ’ = 049.</p>
<p>KLV data &#8211; &#8216;3D Secure OTP RefCode&#8217; = 934.</p>
<p><strong>For more information on KLV data, click <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">here</a></strong></p>

| messageName | String |  0-2048 characters | ✓ | <p>The name of the administrative message being sent</p> |

<h2><a id="3DSAppAuth"></a>Administrative Message &#8211; <strong data-renderer-mark="true">3DSecureAppAuthentication</strong></h2>
<p>This message is used to trigger the process of cardholder authentication. You only need to respond to this message to indicate you have received the message and will initiate the cardholder authentication. This is then followed by calling Paymentology&#8217;s <a href="https://developer.sprint.paymentology.com/companion-api/api-reference/local-api/threedsauthenticationoutcome/">ThreeDSAuthenticationOutcome</a> API.</p>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| reference | String | 1-255 characters | ✓ | <p>The reference of the wallet the 3DS authentication is being actioned on</p> |
| messageName | String | 0-2048 characters | ✓ | <p>The name of the administrative message being sent &#8211; 3DSecureAppAuthentication</p> |
| messageData | String | 0-2048 characters | ✓ | <p>The administrative message data sent over in a <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">KLV format</a>. Will contain the following KLV fields:<br /> 4 &#8211; original transaction amount</p> <p>43 &#8211; merchant description</p> <p>49 &#8211; original currency code</p> <p>For example: 0040512345examplemerchantabc04903978 would mean 123.45 Euro at examplemerchantabc</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Will be the unique transaction ID provided by the ACS.</p> <p>&nbsp;</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

<p>This message is used to inform the client of the final status of the 3DSecure OOB authentication.<br />
Messages include the following:</p>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| reference | String | 1-255 characters | ✓ | <p>The reference of the wallet the 3DS authentication is being actioned on</p> |
| messageName | String | 0-2048 characters | ✓ | <p>The name of the administrative message being sent: 3DSecureAppFinalisation</p> |
| messageData | String | 0-2048 characters | ✓ | <p>The adminisrative message data sent over in a <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">KLV format</a> will contain the following KLV fields: 274 &#8211; status.<br /> Values indicating the status:<br /> 0 &#8211; Successfully received final status<br /> 1 &#8211; Timer on browser expired before response was received<br /> 2 &#8211; General error<br /> 3 &#8211; Transaction cancelled before response was received</p> |

| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
