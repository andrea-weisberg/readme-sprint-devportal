<p>Gives the result of the 3D Secure App Authentication</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| reference | String | 1-255 characters | ✓ | <p>The reference of the wallet the 3DS authentication is being actioned on</p> |
| cardIdentifier | String | 1-20 characters | ✓ | <p>The card number, sequence number or tracking number of the specified card</p> |
| threeDSTransactionID | String |  | ✓ | <p>The original transactionID that was supplied to the client in the <a href="https://developer.sprint.paymentology.com/companion-api/api-reference/remote/administrativemessage/#3DSAppAuth">3DSecureAppAuthentication</a> message</p> |
| status | String |  | ✓ | <p>0 – fully authenticated<br /> 1 – authentication failed<br /> 2 – timeout with cardholder’s app<br /> 3 – general error</p> |
| errorMessage | String |  |  | <p>Message to be displayed to the cardholder</p> |
| transactionID | String | 1-255 characters | ✓ | <p>Will be the unique transaction ID provided by the ACS</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

#### Response schema

| Field | Type | Description |
|---|---|---|
| resultCode | Integer | <p>Status code indicating transaction result</p> |

```xml
<?xml version=""1.0"" encoding=""UTF-8""?>
<methodResponse>
<params>
  <param>
    <value>
      <struct>
        <member>
          <name>resultCode</name>
            <value>
              <int>1</int>
            </value>
        </member>
      </struct>
    </value>
  </param>
</params>
</methodResponse>

```
