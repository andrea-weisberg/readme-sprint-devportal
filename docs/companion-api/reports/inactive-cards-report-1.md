<p data-pm-slice="1 3 []">This report provides client&#8217;s with a list of inactive cards across their campaign. This allows client&#8217;s to better manage their campaign&#8217;s and internal reporting requirements.</p>
<p>The report includes the following details:</p>
<ul>
<li><strong>VoucherNumber</strong> &#8211; the customer’s card number.</li>
<li><strong>SequenceNumber </strong>&#8211; this is a unique sequence card identifier showing a running number for the cards created.</li>
<li><strong>ProfileNumber</strong> &#8211; Profile number linked with the VoucherNumber.</li>
</ul>
