Update the specified card’s bearer details.

[Version 2.4](#version2.4)  
[Version 2.0](#version2.0)

<a id="version2.4"></a>

### Version 2.4

#### Path parameters

| Parameter       | type   | Limits           | required | Description                                                                                                                      |
| --------------- | ------ | ---------------- | :------: | -------------------------------------------------------------------------------------------------------------------------------- |
| terminalID      | String | 10 characters    |    ✓     | The Paymentology issued terminal id of the terminal requesting the transaction                                                   |
| reference       | String | 1-255 characters |    ✓     | The user defined reference to the card; for example a member id or wallet number                                                 |
| cardIdentifier  | String | 1-20 characters  |    ✓     | The card number, sequence number or tracking number of the specified card                                                        |
| firstName       | String | 0-50 characters  |    ✓     | The first name of the card bearer. Field is required but can accept empty string                                                 |
| lastName        | String | 0-50 characters  |    ✓     | The last name of the card bearer. Field is required but can accept empty string                                                  |
| idOrPassport    | String | 0-20 characters  |    ✓     | The id or passport number of the card bearer. Field is required but can accept empty string                                      |
| cellphoneNumber | String | 0-20 characters  |    ✓     | The cellphone number of the card bearer. Field is required but can accept empty string                                           |
| streetAddress   | String | 5 characters     |    ✓     | The street address of the card bearer. No special characters nor alphabetic, example “17014”                                     |
| postalCode      | String | 9 characters     |    ✓     | The postal code of the card bearer. This value is left-justified with right-space-fill, example “12345 ”, “123456789”            |
| cityAddress     | String |                  |    ✓     | City or area of the card bearer.                                                                                                 |
| countryAddress  | String | 3 characters     |    ✓     | ISO Alpha code indicating the country. eg. GBR                                                                                   |
| emailAddress    | String |                  |    ✓     | Email address of the card bearer.                                                                                                |
| transactionID   | String | 1-255 characters |    ✓     | A unique identifier generated by the client, which must not be duplicated over time.                                             |
| transactionDate | Date   |                  |    ✓     | Client generated / local Transaction Date to assist in identifying transactions on the client side                               |
| checksum        | String |                  |    ✓     | HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key |

#### Response schema

| Field      | type    | Description                               |
| ---------- | ------- | ----------------------------------------- |
| resultCode | Integer | Status code indicating transaction result |
| resultText | String  | Text indicating the transaction result    |
