<p>Toggles a voucher feature on or off</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters  | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| customerReference | String | 1-20 characters | ✓ | <p>Customer reference linked with this card</p> |
| trackingNumber | String | 1-20 characters | ✓ | <p>The tracking number of the card</p> |
| featureName | String |  | ✓ | <p>The name of the feature to disable.<br  /> Possible values:</p> <p>CREDIT_APPLICATION_ENABLED</p> <p>DAILY_PINLESS_NFC_DISABLED</p> <p>ENABLE_INTERNATIONAL</p> <p>OPT_IN_VAU</p> <p>OPT_OUT_ABU</p> <p>OPT_OUT_VAU</p> <p>PHYSICAL_CARD_DISABLED</p> |
| featureStatus | Boolean |  | ✓ | <p>The status of the feature. Possible values 1 or 0. To enable the feature this should be 1, to disable it this field should be 0.</p> |
| transactionID | String | 1-255 characters | ✓ | <p data-pm-slice="1 1 []">A unique identifier generated by the client, which must not be duplicated over time.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String | 1-255 characters | ✓ | <p>HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
