<p>Adjust a previous transaction, deduct the requested amount from a wallet.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String |  | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| reference | String |  | ✓ | <p>The reference of the wallet to deduct</p> |
| requestAmount | Integer |  | ✓ | <p>The amount to be deducted in cents</p> |
| narrative | String |  | ✓ | <p>A description of the terminal where the card was used</p> |
| transactionData | String |  | ✓ | <p>Extra information about the transaction in a <a href="https://developer.sprint.paymentology.com/companion-api/klv-lookup/">KLV format</a></p> |
| referenceID | String |  | ✓ | <p>Transaction id of the original transaction to be adjusted</p> |
| referenceDate | Date |  | ✓ | <p>Transaction date (in UTC) of the original transaction or a repeat of the original deduct to be adjusted</p> |
| transactionID | String |  | ✓ | <p>Transaction id number generated by the calling client.</p> <p><em>Note that the Transaction id is not a unique value and may be duplicated over time</em></p> |
| transactionDate | Date |  | ✓ | <p>Transaction date (in UTC) generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
