The Chargeback API contains the endpoints that you call in order to create chargebacks as well as maintain the chargeback lifecycle.

# Available methods

* [API Gateway Token & Connectivity](https://developer.sprint.paymentology.com/chargeback-api/connectivity/) – Generate an authentication token in order to call the rest of the Chargeback API endpoints
* [First Chargeback](https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/first-chargeback/) – Submit a new chargeback
* [Upload Supporting Document](https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/upload-supporting-document/) – Used to upload a supporting document after a chargeback is successfully created.
* [Document Status](https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/document-status/) – Use this endpoint to verify the status of document.
* [Second Presentment Documents](https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/second-presentment-documents/) – Once in the 2nd Presentment phase, this endpoint is used to receive the supporting documents raised by the acquirer for a claim.
* [Pre-Arbitration](https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/pre-arbitration/) – Used to submit submit a Pre-Arbitration case.
* [Query Chargeback](https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/query-chargeback/) – Used to query chargeback data.
