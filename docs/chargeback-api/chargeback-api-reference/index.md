<p>The Chargeback API contains the endpoints that you call in order to create chargebacks as well as maintain the chargeback lifecycle.</p>

<h1>Available methods</h1>
<ul>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/connectivity/">API Gateway Token & Connectivity</a> – Generate an authentication token in order to call the rest of the Chargeback API endpoints</li>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/first-chargeback/">First Chargeback</a> – Submit a new chargeback</li>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/upload-supporting-document/">Upload Supporting Document</a> – Used to upload a supporting document after a chargeback is successfully created.</li>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/document-status/">Document Status</a> – Use this endpoint to verify the status of document.</li>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/second-presentment-documents/">Second Presentment Documents</a> – Once in the 2nd Presentment phase, this endpoint is used to receive the supporting documents raised by the acquirer for a claim.</li>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/pre-arbitration/">Pre-Arbitration</a> – Used to submit submit a Pre-Arbitration case.</li>
<li><a href="https://developer.sprint.paymentology.com/chargeback-api/chargeback-api-reference/query-chargeback/">Query Chargeback</a> – Used to query chargeback data.</li>
</ul>
