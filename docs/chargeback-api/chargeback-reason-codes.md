Below are the Chargeback Reason Codes, these are the only valid reasons acceptable for a chargeback.


| REASON CODE | REASON CODE DESCRIPTION |
| --- | --- |
| 4808 | Authorization-related chargeback |
| 4834 | Point-of-Interaction error |
| 4837 | No cardholder authorization |
| 4849 | Questionable merchant activity |
| 4853 | Cardholder dispute |
| 4870 | Chip liability shift |
| 4871 | Chip liability shift - Lost/Stolen/Never Received Issue (NRI) fraud |
