<p data-pm-slice="1 3 []">This report provides client’s with a list of inactive cards across their campaign. This allows client’s to better manage their campaign’s and internal reporting requirements.</p>
<p>The report includes the following details:</p>
<ul>
<li><strong>VoucherNumber</strong> – the customer’s card number.</li>
<li><strong>SequenceNumber </strong>– this is a unique sequence card identifier showing a running number for the cards created.</li>
<li><strong>ProfileNumber</strong> – Profile number linked with the VoucherNumber.</li>
</ul>
