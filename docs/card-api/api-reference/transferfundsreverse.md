<p>Reverse a TransferFunds transaction that was timed out using the details of the failed transaction.</p>

#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| customerReference | String | 1-20 characters | ✓ | <p>Customer reference linked with this card</p> |
| trackingNumberFrom | String | 1-20 characters | ✓ | <p>The tracking number of the card from which funds were transferred</p> |
| trackingNumberTo | String | 1-20 characters | ✓ | <p>The tracking number of the card onto which funds were loaded</p> |
| pocketUUID | String | 0-255 characters | ✓ | <p>The UUID of the type of pockets between which the funds were transferred, else empty if not applicable</p> |
| requestAmount | Integer |  | ✓ | <p>The amount that was requested in original TransferFunds call</p> |
| transactionID | String | 1-255 characters | ✓ | <p>A unique identifier generated by the client, which must not be duplicated over time.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| referenceID | String | 1-255 characters | ✓ | <p>The value of transactionID that was used with original TransferFunds call</p> |
| referenceDate | Date |  | ✓ | <p>The value of transactionDate that was used with the original TransferFunds call</p> |
| checksum | String | 1-255 characters | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
