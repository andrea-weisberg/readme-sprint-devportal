<p>Set the details of the bearer that is identified by the given tracking number</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters  | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| customerReference | String | 1-255 characters | ✓ | <p>Customer reference linked with this card</p> |
| trackingNumber | String | 1-20 characters | ✓ | <p>Tracking number that identifies the card to be returned</p> |
| transactionID | String | 1-255 characters | ✓ | <p>A unique identifier generated by the client, which must not be duplicated over time.</p> |
| transactionDate | String |  | ✓ | <p>Transaction date generated by the calling client</p> |
| prefix | String | 1-10 characters | ✓ | <p>The salutation for the bearer (eg Mr, Mrs, Miss)</p> |
| firstName | String | 1-50 characters | ✓ | <p>The first name of the bearer</p> |
| middleName | String | 1-50 characters |  | <p>The middle name of the bearer</p> |
| lastName | String | 1-50 characters | ✓ | <p>The last name of the bearer</p> |
| idNumber | String | 1-50 characters | ✓ | <p>The identification number for the bearer</p> |
| mobilePhoneArea | String | 1-10 characters | ✓ | <p>The Mobile Phone Area of the bearer</p> |
| mobilePhoneNumber | String | 1-10 characters | ✓ | <p>The Mobile Phone Number of the bearer</p> |
| countryOfCitizenship | String |  | ✓ | <p>The country of citizenship (three-letter country code defined in ISO 3166-1)</p> |
| dateOfBirth | String | 1-10000000 characters | ✓ | <p>The date of birth (YYYY-MM-DD)</p> |
| screeningRequested | Integer |  | ✓ | <p>Indicator for whether screening was requested (1 if requested)</p> |
| image | String |  | ✓ | <p>The KYC Image for the Bearer</p> |
| streetAddress | String | 5 characters | ✓ | <p>The street address of the card bearer. No special characters nor alphabetic, example “17014”</p> |
| postalCode | String | 9 characters | ✓ | <p>The postal code of the card bearer. This value is left-justified with right-space-fill, example”12345    “,”123456789”</p> |
| cityAddress | String |  | ✓ | <p>City or area of the card bearer.</p> |
| countryAddress | String | 3 characters | ✓ | <div className="param-single d-flex"> <div className="info"> <p>ISO Alpha code indicating the country. eg. GBR.</p> </div> </div> |
| emailAddress | String |  | ✓ | <p>Email address of the card bearer.</p> |
| checksum | String | 1-255 characters | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
