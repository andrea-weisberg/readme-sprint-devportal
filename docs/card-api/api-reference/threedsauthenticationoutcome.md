<p>Gives the result of the 3D Secure App Authentication.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| trackingNumber | String | 1-255 characters | ✓ | <p>Tracking number of the card being used for the transaction</p> |
| customerReference | String |  | ✓ | <p>Customer reference this card is linked to</p> |
| threeDSTransactionID | String |  | ✓ | <p>The original transactionID that was supplied to the client in the 3DSecureAppAuthentication message.</p> |
| status | String |  | ✓ | <p>0 – fully authenticated<br > 1 – authentication failed<br > 2 – timeout with cardholder’s app<br > 3 – general error</p> |
| errorMessage | String |  |  | <p>Message to be displayed to the cardholder</p> |
| transactionID | String |  | ✓ | <p>The unique transaction id provided by the ACS</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

#### Response schema

| Field | type | Description |
|---|---|---|
| terminalID | String | <p>Echo</p> |
| trackingNumber | String | <p>Echo</p> |
| customerReference | String | <p>Echo</p> |
| threeDsTransactionID | String | <p>Echo</p> |
| status | String | <p>Echo</p> |
| errorMessage | String | <p>Echo</p> |
| clientTransactionID | String | <p>Echo</p> |
| serverTransactionID | String | <p>Transaction id number generated by Paymentology</p> |
| resultCode | Integer | <p>Code indicating transaction result</p> |
| resultText | String | <p>Text indicating transaction result</p> |
