<p>MostRecentTransactions provides the latest transactions on the basis of following two criteria:</p>
<ol>
<li>Date Range (Start Date and End Date)</li>
<li>Transaction Count (The number of transaction that needs to be returned in the api call)</li>
</ol>



<!-- spacing: desktop=20, mobile=10 -->


#### Path parameters

| Parameter | Type | Limits | Required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal ID of the terminal requesting the transaction</p> |
| customerReference | String | 1-255 characters | ✓ | <p>Customer reference linked with this card</p> |
| trackingNumber | String | 1-20 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>The tracking number of the card to retrieve the transactions for</p> </div> </div> |
| pocketUUID | String | 1-255 characters | ✓ | <p>The UUID of the pocket to retrieve the transactions for</p> |
| transactionID | String | 1-255 characters | ✓ | <div class="param-single d-flex"> <div class="info"> <p>A unique identifier generated by the client, which must not be duplicated over time.</p> </div> </div> |
| transactionDate | Date |  | ✓ | <div class="param-single d-flex"> <div class="info"> <p>Starting date of the date range you wish to pull the transactions for. End date will be today&#8217;s date.</p> </div> </div> |
| numTransactions | Integer |  | ✓ | <p>The number of transaction(s) that need to be returned</p> |
| checksum | String |  | ✓ | <section class="tutuka-block tutuka-block--api-request"> <div class="api-reference"> <div class="api-reference__single"> <div class="params-wrapper"> <div class="param-single d-flex"> <div class="info"> <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> </div> </div> </div> </div> </div> </section> |

| Field | Type | Description |
|---|---|---|
| clientTransactionID | String | <p>Echo of incoming value <strong>transactionID</strong></p> |
| statement | Array | <p data-renderer-start-pos="3053">The transaction history of the card</p> <p data-renderer-start-pos="3096"><strong data-renderer-mark="true">transactionType</strong>, string</p> <p data-renderer-start-pos="3121">The identifier depicting the type of transaction.</p> <p data-renderer-start-pos="3172">1 – Load</p> <p data-renderer-start-pos="3182">2 – Deduction</p> <p data-renderer-start-pos="3197">3 – Authorization</p> <p data-renderer-start-pos="3282"><strong data-renderer-mark="true">transactionDate</strong>, date</p> <p data-renderer-start-pos="3305">Date and time of the transaction, string in ISO 8601 format eg. “20150121T02:04:35”</p> <p data-renderer-start-pos="3393"><strong data-renderer-mark="true">transactionAmount</strong>, double</p> <p data-renderer-start-pos="3420">Transaction amount</p> <p data-renderer-start-pos="3443"><strong data-renderer-mark="true">transactionDescription</strong>, string</p> <p data-renderer-start-pos="3475">Transaction description</p> <p data-renderer-start-pos="3814"><strong data-renderer-mark="true">systemDate</strong>, date</p> <p data-renderer-start-pos="3832">Paymentology’s system date in UTC +7 time zone, string in ISO 8601 format eg. “20150121T02:04:35”</p> |
| resultCode | String | <div class="param-single d-flex"> <div class="info"> <p>Status code indicating transaction result</p> </div> </div> |
| terminalID | String | <p>Echo</p> |
| customerReference | String | <p>Echo</p> |
| resultText | String | <div class="param-single d-flex"> <div class="info"> <p>Text indicating transaction result</p> </div> </div> |
| pocketUUID | String | <p>Echo</p> |
| serverTransactionID | String | <div class="param-single d-flex"> <div class="info"> <p>Transaction id generated by Paymentology</p> </div> </div> |
