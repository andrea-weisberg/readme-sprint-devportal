<p>Get the details of the bearer that is identified by the given tracking number</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| customerReference | String | 1-255 characters | ✓ | <p>Customer reference linked with this card</p> |
| trackingNumber | String | 1-20 characters | ✓ | <p>Tracking number that identifies the card to be returned</p> |
| transactionID | String | 1-255 characters | ✓ | <p>A unique identifier generated by the client, which must not be duplicated over time.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |

#### Response schema

| Field | type | Description |
|---|---|---|
| terminalID | String | <p>Echo</p> |
| customerReference | String | <p>Echo</p> |
| trackingNumber | String | <p>Echo</p> |
| clientTransactionID | String | <p>Echo</p> |
| serverTransactionID | String | <p>Transaction id number generated by Paymentology</p> |
| prefix | String | <p>The salutation for the bearer (eg Mr, Mrs, Miss)</p> |
| firstName | String | <p>The first name of the bearer</p> |
| middleName | String | <p>The middle name of the bearer</p> |
| lastName | String | <p>The last name of the bearer</p> |
| idNumber | String | <p>The identification number for the bearer</p> |
| mobilePhoneArea | String | <p>The Mobile Phone Area of the bearer</p> |
| mobilePhoneNumber | String | <p>The Mobile Phone Number of the bearer</p> |
| screeningRequested | Integer | <p>Indicator for whether screening was requested (1 if requested)</p> |
| screeningResultCode | Integer | <p>Status code indicating screening result</p> |
| screeningResultText | String | <p>Text indicating screening result</p> |
| image | String | <p>The KYC Image for the Bearer</p> |
