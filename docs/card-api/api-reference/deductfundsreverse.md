<p>Reverse a deduct that was previously requested but had potentially failed.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| customerReference | String | 1-20 characters | ✓ | <p>Customer reference linked with this card</p> |
| trackingNumber | String | 1-20 characters | ✓ | <p>The tracking number of the card to reverse the deduct for</p> |
| pocketUUID | String | 0-255 characters | ✓ | <p>UUID of the pocket to reverse the deduct for if applicable. Else leave empty.</p> |
| requestAmount | Integer |  | ✓ | <p>The amount that was requested in original DeductFunds call</p> |
| transactionID | String | 1-255 characters | ✓ | <p>A unique identifier generated by the client, which must not be duplicated over time.</p> |
| transactionDate | Date |  | ✓ | <p>Transaction date generated by the calling client</p> |
| referenceID | String | 1-255 characters, | ✓ | <p>The value of transactionID that was used with original DeductFunds call</p> |
| referenceDate | Date |  | ✓ | <p>The value of transactionDate that was used with the original DeductFunds call</p> |
| checksum | String |  | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
