### Version 1.3

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | The Paymentology issued terminal id of the terminal requesting the transaction |
| customerReference | String |  1-255 characters | ✓ | Customer reference linked with this card |
| trackingNumber | String | 1-20 characters | ✓ | The tracking number of the card to retrieve the statement for |
| pocketUUID | String | 0-255 characters | ✓ | The UUID of the type of pocket to retrieve the statement for if applicable. Else, leave empty. |
| startDate | Date |  | ✓ | The date that the statement should start from |
| endDate | Date |  | ✓ | The date that the statement should end on |
| transactionID | String | 1-255 characters | ✓ | A unique identifier generated by the client, which must not be duplicated over time. |
| transactionDate | Date |  | ✓ | Transaction date generated by the calling client |
| checksum | String |  | ✓ | HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key |
