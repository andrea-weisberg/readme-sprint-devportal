<p>Reverse an PocketTransfer transaction that was timed out using the details of the failed transaction.</p>

#### Path parameters

| Parameter | type | Limits | required | Description |
|---|---|---|:--:|---|
| terminalID | String | 10 characters | ✓ | <p>The Paymentology issued terminal id of the terminal requesting the transaction</p> |
| customerReference | String | 1-20 characters | ✓ | <p>Customer reference linked with card indicated in trackingNumberFrom field</p> |
| trackingNumber | String | 1-20 characters | ✓ | <p>The tracking number of the card that the pockets are linked to</p> |
| pocketTypeUUIDFrom | String | 1-255 characters | ✓ | <p>The UUID of the pocket to transfer funds from</p> |
| pocketTypeUUIDTo | String | 1-255 characters | ✓ | <p>The UUID of the pocket to transfer funds to</p> |
| requestAmount | Integer |  | ✓ | <p>The requested amount to be loaded on the card and deducted from the profile</p> |
| transactionID | String | 1-255 characters | ✓ | <p>A unique identifier generated by the client, which must not be duplicated over time.</p> |
| transactionDate | String |  | ✓ | <p>Transaction date generated by the calling client</p> |
| referenceID | String | 1-255 characters | ✓ | <p>value of transactionID that was used for original PocketTransfer call</p> |
| referenceDate | Date |  | ✓ | <p>value of transactionDate that was used for original PocketTransfer call</p> |
| checksum | String | 1-255 characters | ✓ | <p>HMAC-SHA256 hashed signature of the concatenated method name with all argument values using the terminal password as private key</p> |
