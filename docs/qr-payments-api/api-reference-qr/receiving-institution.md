## Available Methods

* [CreateQRData](https://developer.sprint.paymentology.com/qr-payments-api/api-reference/receiving-institution/#CreateQRData) – The method returns a QR including the received information and a new card number linked to the input reference with every request.
* [DeactiveateQR](https://developer.sprint.paymentology.com/qr-payments-api/api-reference/receiving-institution/#DeactivateQR) – Deactivate a card.

## CreateQRData

The method returns a QR including the received information and a new card number linked to the input reference with every request.

#### Path parameters

| Parameter            | type   | Limits           | required | Description                                                                                                                                    |
| -------------------- | ------ | ---------------- | :------: | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| terminalID           | String | 10 characters    |     ✓    | The Paymentology issued terminal id of the terminal requesting the transaction                                                                 |
| merchantCategoryCode | String | 1-4 characters   |     ✓    | Mastercard defined merchant category code                                                                                                      |
| merchantName         | String | 40 characters    |     ✓    | Business name of the merchant                                                                                                                  |
| merchantCity         | String | 25 characters    |     ✓    | City of the merchant                                                                                                                           |
| countryCode          | String | 3 characters     |     ✓    | ISO alpha country code of the recipient/merchant Ex. ZAF                                                                                       |
| reference            | String | 1-255 characters |     ✓    | The user defined reference to the card; for example a member id or wallet number                                                               |
| transactionID        | String | 1-40 characters  |     ✓    | Transaction id number generated by the calling client                                                                                          |
| transactionDate      | Date   |                  |          | Client generated / local transaction date to assist in identifying transactions on the client side                                             |
| optionalData         | String |                  |          | Struct with optional fields, right now only “postalCode” field is accepted. See above for details. The maximum length of the postalCode is 10. |
| checksum             | String |                  |     ✓    | HMAC-SHA1 hashed signature of the concatenated method name with all argument values using the terminal password as private key                 |
