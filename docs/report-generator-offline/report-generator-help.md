## About Report Generator

You can use Report Generator to automatically generate and download to your reports from the test environment with your own test data.

Reports are generated on demand, which can take a few seconds, please be patient. Only click “Generate Report” once and wait for the download window to appear.


## How to use Report Generator

- Go to [Report Generator](report-generator-help) under [Tools](../tools/)

- Choose the date that you want to run the report for

- Choose the report that you want to run

- Click on “Generate Report” **once** and wait for the “Download File” popup to appear
